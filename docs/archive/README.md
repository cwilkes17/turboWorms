`docs/PRODUCT.md` (what the game should do) and `docs/ARCHITECTURE.md` (how the
code is organized). They're kept here for history only — **agents and
contributors should not treat these as current truth.** Where they conflict
with PRODUCT.md / ARCHITECTURE.md, the newer docs win.

- `game_design.md` — earliest gameplay design notes (superseded by PRODUCT.md)
