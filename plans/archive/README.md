# Archived execution plans

These `*.exec.md` files were the original per-feature build instructions used
to hand each system (movement, food, abilities, collision, integration,
networking, minimap) to a coding agent one at a time during the initial
prototype build. The systems they describe now exist in code, and the
authoritative references are `docs/ARCHITECTURE.md` (structure/data flow) and
`docs/PRODUCT.md` (gameplay rules/numbers).

Kept for history only — **not current truth.** One exception: `minimap.exec.md`
describes a feature that is spec'd in PRODUCT.md but not yet built; see
"Known gaps" in ARCHITECTURE.md before starting that work, and treat this file
as background context rather than the final spec.
